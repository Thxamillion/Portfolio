# QuinGPT

AI-powered interactive portfolio. Ask me anything.

**Live:** [quinortiz.com](https://quinortiz.com)

## Tech Stack
- Next.js 15 + TypeScript
- OpenAI GPT-4 with streaming
- AWS Lambda + CloudFront (via SST)
- Terraform for infrastructure

## Features
- Conversational interface
- AI tools for projects, skills, resume
- Real-time streaming responses
